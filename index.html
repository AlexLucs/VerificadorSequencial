Verificador sequencial de imagens v1.0.0

Insira a URL de uma imagem. O verificador incrementa o número antes de _s.jpg. Uma lacuna de um índice é tolerada; o fim é confirmado quando o índice ausente e o índice seguinte falham. Se o vídeo tiver o arquivo VTT de miniaturas, a busca para na última folha, cada minuto é marcado sobre as folhas e o tempo de cada miniatura aparece ao passar o mouse.

Aceita URL direta ou link Markdown no formato [texto](URL).

Extrair URL do perfil

Crie um favorito no navegador e cole o código abaixo no campo URL/endereço. Na página do perfil, clique no favorito antes de passar o mouse sobre a barra de progresso. O painel captura novas requisições JPG. Clique em “Copiar URL capturada”; o painel fechará automaticamente e a URL ficará na área de transferência.

Para capturar a primeira imagem, passe o mouse sobre o início da timeline. Para outra imagem, mova o cursor para o ponto desejado e copie a URL mais recente.

Histórico de buscas

As entradas são salvas somente quando uma busca iniciada termina ou é interrompida. As URLs ficam guardadas neste navegador; se contiverem tokens de acesso, use “Limpar histórico” ao terminar.
